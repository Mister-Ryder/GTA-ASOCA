Why a small Gaussian loss need not imply learned fine structure
  Let g in [0,1] be zero outside the GT foreground, q=sigmoid(K*z+b),
  t=0.5+0.5*g and L_G=lambda/N * sum_i(q_i-t_i)^2.
  A constant q=0.5 gives raw MSE=0.25*mean(g^2)<=foreground_fraction/4.
  For an illustrative 1% foreground fraction this is at most 0.0025, or 0.025
  with lambda=10, even if every positive target is ignored. These are mathematical
  bounds, not measurements of the current patches. The best bank-wide constant
  is mean(t), with raw MSE=Var(t)=0.25*Var(g). A per-patch optimal constant would
  use that patch's GT and is an oracle diagnostic, not an independently fit model.
  Small branches occupy few voxels. Per-volume maximum normalization can also
  reduce some branch amplitudes; its actual effect must be measured by radius
  and target-amplitude strata. Pointwise MSE imposes no explicit path-connectivity
  constraint. The 0.5 offset is historical, and is not itself an implementation bug.
  dL_G/du_i=2*lambda/N*(q_i-t_i)*q_i*(1-q_i), u=K*z+b. Sigmoid saturation and the
  learned convolution affect how this reaches logits. Increasing lambda scales
  this local derivative at fixed weights, but does not guarantee better training,
  parameter updates or Dice/ASSD; loss conflicts, clipping and AdamW remain relevant.
  Softmax segmentation depends on margin z1-z0, not on common mode z0+z1.
  The Gaussian head sees both, so it can encode an auxiliary field in common mode
  without changing segmentation probability. This is a possible mechanism,
  not an observed conclusion about the current checkpoints.

What the existing training probe establishes
  code/train.py:253-270 obtains separate weighted Gaussian and segmentation
  derivatives with respect to main logits using autograd.grad. The temporary
  factor 1024 is removed; no optimizer update or parameter .grad accumulation is
  added by that probe. Scaling reduces FP16 underflow risk, but does not create
  an exact full-precision measurement. The logged ratio and cosine describe
  the sampled main-output space, not full shared-parameter gradients.
  code/losses.py:109-112 weights DS 1,0.5,0.25 and divides by 1.75. Thus the main
  logits derivative contains only 4/7 of the main segmentation-head objective;
  sibling DS paths are excluded. Classification/guidance objectives and the
  optimizer's moments/clipping are not represented by that ratio.
  code/train.py:166-170 puts all non-classifier parameters, including gau_final,
  in segmentation_parameters. Its aggregate gradient norm (:272) cannot attribute
  gradients to the segmentation loss alone. Default 250-step probing with 125
  steps/epoch observes the first batch of alternate epochs, not all batches.

Prepared companion: ops/diagnose_gaussian.py
  This independent script does not edit frozen code, create an optimizer, call
  backward(), update weights/BN, select checkpoints or start training. --plan
  uses only the standard library; missing local inputs are reported explicitly.
  --cpu-readiness imports dependencies and validates checkpoint/config/cache
  identity on CPU, but performs no forward pass and never initializes CUDA.
  Actual diagnostics must be explicitly invoked later; default device is CPU.
  The script uses fixed original training-sampler indices, stratified to obtain
  two patches per each of the 28 training patients (56 by default). Index/seed/
  bank epoch are fixed before looking at GT. Frozen CohortDataset supplies the
  same sampling policy and targets; geometric/positive sampling can use GT as
  it does in training. CT augmentation is disabled. This is not an estimate of
  the naturally sampled training-patch population or an independent test bank.
  The saved model is in eval mode. CT alone enters its forward. FP32 detached
  logits then feed the frozen Gaussian head and objective for output derivatives.
  These are eval-mode, batch-one, FP32 diagnostics, not actual training updates.
  Common=(dL/dz0+dL/dz1)/sqrt(2); margin=(dL/dz1-dL/dz0)/sqrt(2). Energies,
  Gaussian/segmentation norm ratios and cosine are recorded in these bases.
  Report MSE and both constant baselines over all voxels, GT foreground, all
  background, outside-GT shells (0,1]mm and (1,3]mm, and background >3mm.
  Empty-patch shells are empty and distance to foreground is treated as infinity.
  No shell extends outside the patch. Correlations compare foreground probability
  and Gaussian prediction against the cached field, both globally and within GT.
  Correlation is descriptive and cannot establish connectivity or benefit.
  Source/script/checkpoint/config/manifest hashes, seed, sampler, patch starts,
  bank indices, patients, checkpoint epoch, lambda and limitations are retained.
