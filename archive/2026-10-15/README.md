# Existing work archive — 2026-10-15

This directory preserves work already produced before the user's instruction to
stop further research and upload the existing materials. Files retain their
original directory structure and historical status; no new experiment or
scientific interpretation was added for this archive.

- `ASOCA_Extension/code`, `development`, `repair_cldice`: earlier source versions.
- `ASOCA_Extension/fidelity_v2/code`: reference implementation.
- `ASOCA_Extension/fidelity_v2/variants`: existing B, rotation and encoder-supervision variants, with their existing records.
- Both `server_records` trees: existing configurations, logs, per-case results, trajectories, predictions, figures and diagnostics.
- `docs`, `curves`, `prior_audit`, `ops`, `ops_inputs` and `autoresearch`: existing reports and execution history. Historical plans are not evidence of execution.
- `FILES.json`: uploaded file inventory.

The four available final trained checkpoints are provided as a separate
[Release asset](https://github.com/Mister-Ryder/GTA-ASOCA/releases/tag/experiment-archive-2026-10-15).
Their original paths and checksums are listed in `CHECKPOINT_FILES.json`.
Repeated checkpoint copies are not duplicated. Raw CT/GT data, caches, private
airway initialization weights, credentials, Git metadata, bytecode and duplicate
transport archives are not included.

The repository's earlier top-level documentation remains the historical
reference-source release. Use the archived files when consulting subsequent work.
