Historical contribution and the extension boundary
  Shared problem: heterogeneous, thin, branching tubular anatomy, with severe
  foreground/background and branch-scale imbalance. Airways are respiratory
  anatomy, so a cardiovascular-only framing would not include both tasks.
  Preserve the three attribute heads, hierarchical guidance placement,
  multiscale decoder fusion and radius-aware centreline Gaussian auxiliary.
  ASOCA branch-depth, morphology and spatial-context targets are training
  supervision. They are never input to the network during validation/testing.
  Do not describe auxiliary attribute bins as semantic coronary label classes.
  Root-based depth strata preserve ordered generation semantics; they require
  explicitly documented graph construction and root-selection rules.
  Normal/diseased cohorts are patient groups, not voxel segmentation classes.

Relevant manuscripts
  neurips_2025_6600.pdf describes HARL and matches the historical model.
  neurips_2026(13).pdf describes TCFF/CoW, a different later formulation; its
  evidential fusion claims should not be assigned to this GTAirway code.
  The historical Gaussian target is an empirical geometric regularizer. The
  source does not establish a guarantee of topology preservation or implement
  a geodesic distance transform. Attribute prediction likewise should not be
  described as formal disentanglement without additional evidence.

Deep supervision
  The canonical enhanced trainer supervises the final segmentation, full-size
  Gaussian output, global attribute classification and a low-resolution
  guidance map. It does not supervise multiple decoder segmentation outputs.
  This statement concerns the enhanced trainer only. The original base model
  pretraining used two segmentation outputs, including encoder/decoder fusion;
  the original workflow must not be described as having no such supervision.
  The current enhanced forward does not call the encoder fusion output. The
  ASOCA additions below are decoder-only DS, not encoder+decoder DS restoration.
  ASOCA model.py adds optional half/quarter-resolution segmentation heads on
  the existing 64/128 decoder features. These return raw logits in that order.
  Plain U-Net receives the same optional heads. Deep supervision needs matched
  controls/ablations; it is a training improvement, not a new method claim.
  Use soft occupancy or upsampled auxiliary logits when necessary to prevent
  target downsampling from deleting thin vessels; trainer chooses the policy.

Execution changes
  The ASOCA wrapper exposes raw logits and retains the original sigmoid
  Gaussian mapping from those logits. It jointly trains the original prior
  classifier from scratch without loading historical pretrained weights in
  the current ASOCA run. The earlier blanket claim that these weights were
  absent was incorrect: backups now contain BAS599, classifier improved/
  hybrid100, and joint GTA350 candidates. Their compatibility and correspondence
  to the original best checkpoint remain unverified. Review pretrained-weight
  recovery and the original staged schedule before resuming new ablations.
  This differs from the original frozen/partial/unfrozen checkpoint schedule
  and must be disclosed. No inference threshold correction is added.
  No-prior removes the complete classifier/guidance path and 16-channel map.
  No-Gaussian removes its output head. No-balancing keeps the same model and
  removes both geometric sampling and anatomy segmentation weights; it is a
  combined sampling/loss-balancing ablation. unet_cldice shares plain U-Net.

Final default training objective
  Segmentation retains the historical softmax background squared-Dice plus
  foreground power-Dice with alpha=2 and delta=0.1, summed over flattened
  batches. Background Dice now weights the denominator symmetrically to keep
  each Dice term bounded in [0,1]; this is the single mathematical correction
  to that historical segmentation formula. Foreground power-Dice is unchanged.
  All controlled baselines use the same segmentation core, unweighted. Optional
  DS applies the same core to final/half/quarter logits with normalized weights
  [1,.5,.25]. Auxiliary logits are upsampled to full-size targets, preserving
  thin vessel occupancy rather than downsampling masks to hard labels.
  Anatomy weights preserve generation>=5:1.5, generation>=3:1.2, other:1.0,
  multiplied by 1.3 only for structure==3 (the historical bifurcation bin).
  Attribute supervision retains focal gamma=2 and generation +1.5*structure
  +location losses. Uniform alpha replaces only the historical airway-specific
  class weights because the coronary target distributions/semantics differ.
  Structure certainty retains MSE between the assigned-target-class certainty
  and the detached classifier correctness indicator, multiplied by 0.5 within
  the attribute loss. This is the original empirical correctness objective;
  formal probability calibration is not claimed.
  Attribute loss coefficient is min(.5,.1+.01*epoch) from epoch zero, reflecting
  joint initialization rather than waiting for pretrained-model unfreezing.
  The 16-channel guidance map retains .1*MSE to average-pooled foreground mask
  with pool/stride4, explicitly expanded across channels rather than relying
  on implicit broadcasting.
  Gaussian supervision retains 10*MSE and converts cached unit fields to the
  historical loader convention .5+.5*field inside the loss. No new foreground
  balancing, field transform or field coefficient is introduced.
  unet_cldice adds .2*soft-clDice to the shared segmentation objective.
  Historical segmentation-to-classifier enhanced_features are returned but
  remain unused by the loss. Their convolution modules are inactive training
  paths, as in the original; no new feedback supervision is invented.

Historical implementation issues the clean runner must avoid
  Distributed sampler repeats the same seeded draws on each rank rather than
  sharding a shared sampled sequence. Single-GPU execution avoids this issue.
  Classifier-only dataset path references an uninitialized gaussian_img2.
  Segmentation labels are ScalarImage in TorchIO, inviting linear interpolation
  instead of nearest-neighbour interpolation. Spatial metadata remains fixed
  after flips/affines and may become inconsistent with anatomical location.
  A frozen classifier remains in train mode, updating BatchNorm running stats.
  Partial unfreeze at epoch 50 is inert while forward joint_training=False
  still disables classifier gradients until epoch 70.
  dice_loss_weights applies weights only to the numerator, so weights greater
  than 1 can make the loss negative. Symmetric weighting is an explicit fix.
  An initial suspected segmentation/label cross-batch broadcasting issue was
  ruled out: both original Dice inputs are flattened before multiplication.
  The canonical best checkpoint is chosen by training Dice/loss, not a held-out
  validation score. The new runner should use a patient-level validation split.
  Historical unused feedback/uncertainty and backbone modules require honest
  registered versus active parameter accounting.
